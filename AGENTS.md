# AGENTS.md

Each numbered phase in [PHASES.md](PHASES.md) is a separate development goal, stored in `.work/fase-N/`. All delivery increments within a goal use that same directory. Approved project-wide decisions remain in force across goals.

The user authorizes minor validation corrections, such as fixing a mismatched platform property name, without another approval when they preserve the approved behavior and acceptance expectations. Changes to those expectations still require approval.
