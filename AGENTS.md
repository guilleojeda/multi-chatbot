# AGENTS.md

Each numbered phase in [PHASES.md](PHASES.md) is a separate development goal, stored in `.work/fase-N/`. All delivery increments within a goal use that same directory. Approved project-wide decisions remain in force across goals.

The user authorizes minor validation corrections, such as fixing a mismatched platform property name, without another approval when they preserve the approved behavior and acceptance expectations. Changes to those expectations still require approval.

El proyecto todavía no tiene usuarios reales: los datos, cuentas y sesiones actuales son pruebas descartables. El usuario autoriza eliminarlos o reiniciarlos cuando haga falta dentro del proyecto. El diseño de fase 8 no debe incorporar compatibilidad con versiones o formatos anteriores, migraciones, backfills ni publicaciones escalonadas para conservar esas pruebas. La conservación de conversaciones y la continuidad de generaciones siguen siendo comportamiento requerido del producto; la limpieza técnica del entorno de pruebas es una operación distinta.
